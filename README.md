# MorCraftSmp Web Sitesi

Türkçe, mobil uyumlu ve GitHub Pages üzerinde yayınlanmaya hazır statik sunucu tanıtım sitesi.

## İçerik
- Sunucu IP: `MorCraftSmp.aternos.me`
- VIP: 30.000 coin
- VIP+: 60.000 coin
- MVP: 100.000 coin
- Gerçek para ile satış yoktur.
- IP kopyalama, mobil menü ve rütbe bilgi pencereleri çalışır.

## Yayınlama
GitHub deposunda **Settings → Pages** bölümüne girin. **Deploy from a branch** seçin, branch olarak `main`, klasör olarak `/ (root)` seçip kaydedin.

## Önemli: Oyun içi bakiye bağlantısı
Bu sürüm tanıtım ve mağaza arayüzüdür. Rütbe pencereleri satın alma yapmaz ve coin düşmez. Sunucudaki mevcut satış/ekonomi sistemiyle güvenli satın alma bağlantısı kurulmadan web üzerinden gerçek işlem yapılmamalıdır.

Bağlantı için sunucunun hangi ekonomi/mağaza eklentisini kullandığı, oyuncu bakiyesinin nasıl okunduğu ve rütbelerin nasıl verildiği bilinmelidir. Sunucuya özel API anahtarları veya yönetici şifreleri tarayıcı JavaScript dosyalarına konulmamalıdır. İşlemler güvenli bir sunucu tarafı API üzerinden yapılmalıdır.
